Itens a serem entregues no projeto de Banco de Dados:
1. Apresentação do projeto: [10 pontos]
• Capa, com o título do projeto e nomes dos integrantes do grupo.
• Sumário.
• Objetivo e breve descrição das principais funcionalidades da solução.
2. Descrição das tabelas do modelo relacional: [20 pontos]
• O modelo de relacional deverá ter, no mínimo, 5 (cinco) tabelas.
• Descrição sobre o significado e objetivo de cada tabela.
3. Descrição das colunas das tabelas: [20 pontos]
• Nome de cada coluna das tabelas.
• Definição do tipo de dados e tamanho das colunas.
• Indicação se a coluna é mandatória (“not null”).
• Indicação das eventuais validações de cada coluna: chave primária (PK),
chave estrangeira (FK), chave de unicidade (UK), etc.
• Descrição sobre o significado e objetivo de cada coluna das tabelas.
