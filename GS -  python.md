DESCRIÇÃO DA ENTREGA
Cada grupo deverá escolher um problema relacionado à
economia espacial e desenvolver uma aplicação em Python
utilizando conceitos fundamentais da disciplina de
Estruturas de Dados.
O projeto deverá realizar análise, organização e
processamento de dados reais obtidos de fontes públicas,
APIs, arquivos CSV, bases governamentais ou plataformas
abertas relacionadas ao tema escolhido.
A solução desenvolvida deve demonstrar, obrigatoriamente, a
aplicação prática das principais estruturas de dados e
algoritmos estudados durante a disciplina.
TEMAS SUGERIDOS
Os grupos poderão escolher livremente um dos temas abaixo
ou propor outro tema relacionado à economia espacial:
• Monitoramento climático e eventos extremos
• Incêndios florestais e focos de calor
• Agricultura de precisão e produtividade
• Qualidade do ar e poluição atmosférica
• Rastreamento orbital e comportamento de satélites
• Telecomunicações e conectividade remota
• Meteoritos e padrões geográficos
• Desastres naturais e gestão de riscos
OBJETIVO DO PROJETO
Os grupos deverão:
• Identificar um problema relevante dentro do tema
escolhido.
• Coletar e organizar dados reais.
• Desenvolver uma aplicação em Python para análise e
manipulação desses dados.
• Aplicar estruturas de dados e algoritmos estudados em
aula.
• Demonstrar como a solução pode auxiliar na
interpretação, monitoramento ou tomada de decisão
relacionada ao problema escolhido.
REQUISITOS OBRIGATÓRIOS
O projeto deve obrigatoriamente implementar e demonstrar o
uso dos seguintes conteúdos da disciplina:
Estruturas de Dados
• Pilhas
• Filas
• Listas ligadas (simples ou duplamente ligadas)
Algoritmos
• Pelo menos um algoritmo de busca
o Busca linear
o Busca binária
o Ou outra equivalente
• Pelo menos um algoritmo de ordenação
o Bubble Sort
o Selection Sort
o Insertion Sort
o Merge Sort
o Quick Sort
o Ou equivalente
Outros requisitos técnicos
• Manipulação de arquivos ou bases de dados
• Modularização do código
• Funções e organização em múltiplos arquivos quando
necessário
• Tratamento de erros utilizando try/except
• Logs simples ou mensagens de execução
• Interface em terminal ou interface gráfica simples
(opcional)
LIBERDADE TECNOLÓGICA
Os grupos poderão utilizar bibliotecas adicionais para
enriquecer o projeto, tais como:
• Pandas
• Matplotlib
• NumPy
• OpenCV
• PyQt / Tkinter
• APIs públicas
• Bibliotecas geoespaciais
• Ferramentas de visualização de dados
O uso dessas bibliotecas é opcional e não substitui a
obrigatoriedade de implementação das estruturas de dados e
algoritmos solicitados.
CRITÉRIOS DE AVALIAÇÃO
Vídeo da solução (40 pontos)
O grupo deverá gravar um vídeo demonstrando:
• O problema escolhido
• A origem dos dados utilizados
• O funcionamento do sistema
• As estruturas de dados implementadas
• Os algoritmos de busca e ordenação utilizados
• Demonstração prática da aplicação
Repositório GitHub (30 pontos)
O projeto deverá ser disponibilizado em um repositório
GitHub público.
README obrigatório
O README deve conter:
• Descrição do projeto
• Objetivo da solução
• Tema escolhido
• Fonte dos dados utilizados
• Estruturas de dados implementadas
• Algoritmos utilizados
• Tecnologias e bibliotecas utilizadas
• Explicação do funcionamento
• Instruções de execução
• Nome completo dos integrantes do grupo
Também deverão estar disponíveis:
• Código-fonte completo
• Arquivos auxiliares
• Bases de dados utilizadas (quando permitido)
• Arquivo requirements.txt (quando aplicável)
Qualidade técnica e aplicação dos conceitos (30 pontos)
Serão avaliados:
• Correta implementação das estruturas de dados
• Correta implementação dos algoritmos
• Organização e modularização do código
• Clareza e legibilidade
• Tratamento de erros
• Qualidade da análise desenvolvida
• Criatividade e complexidade da solução
• Relação do projeto com o tema proposto
